# Hospital Waiting Times & Performance Analytics

## Project Overview

This project presents an interactive hospital performance analytics dashboard developed using Microsoft Power BI. It explores patient waiting times, hospital admissions, departmental referrals, patient demographics and patient satisfaction.

The project demonstrates how data visualisation, data modelling and DAX measures can be used to explore healthcare service performance and support evidence-informed decision-making.

## Key Insights

The following findings were calculated from the educational dataset containing 2,000 hospital visit records.

- **Admission patterns:** 993 records (49.65%) were marked as admitted, while 1,007 (50.35%) were marked as not admitted.

- **Waiting times:** The average recorded waiting time was approximately 40 minutes, with a median of 39.9 minutes.

- **Patient satisfaction:** The average satisfaction score was 6.49 out of 10.

- **Patient demographics:** The average recorded patient age was approximately 40 years.

- **Departmental referrals:** General Practice had the highest number of recorded referrals (314), followed by Cardiology (297) and Neurology (288).

- **Administrative flags:** 1,082 records were marked "Admin Required", while 918 were marked "No Admin".

These findings describe the supplied dataset and should not be interpreted as actual NHS performance statistics.

## Data Quality and Limitations

- **Educational dataset:** The data is used for analytical practice and does not represent verified NHS hospital performance.

- **Missing referral information:** 287 of the 2,000 records have no department referral recorded. These records should be considered when interpreting referral analysis.

- **Repeated patient identifiers:** Five records have a Patient ID that appears more than once. Counts of records and counts of distinct patients may therefore differ.

- **Interpretation:** The findings describe patterns in this dataset. They do not establish causation or necessarily generalise to other hospitals.

## Dataset

The project uses an educational hospital emergency department dataset covering 2021–2023.

The dataset contains patient-level records and variables relating to demographics, admissions, waiting times, referrals and satisfaction.

**Important:** This is an educational analytics project. The figures should not be interpreted as actual NHS statistics or as representing the performance of a real hospital.

## Limitations

- Findings depend on the fields and records available in the supplied dataset.
- Results describe the dataset and should not automatically be generalised to other hospitals.
- The analysis identifies patterns and relationships but does not establish causation.
